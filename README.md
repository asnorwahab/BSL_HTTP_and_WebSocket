## 1. Project Description

This project is a **Personal Portfolio Landing Page** developed using HTML and CSS, with **Bonezegei Scripting Language (BSL)** serving as the backend HTTP server. The website provides a simple and organized interface for presenting personal information, technical skills, and projects.

The project demonstrates basic web development, HTTP server configuration, and local web hosting using the Bonezegei framework.

### Tech Stack
- **HTML5** – Structures the content of the portfolio.
- **CSS3** – Provides styling, layout, and visual design.
- **Bonezegei Scripting Language (BSL)** – Handles HTTP requests and serves web pages.
- **Visual Studio Code** – Used for development and editing.
- **Git & GitHub** – Used for version control and repository management.

## 2. Setup & Execution Steps

Follow the instructions below to set up and run the personal portfolio website locally.

### Step 1: Install the Requirements

Make sure the following tools are installed:

- Visual Studio Code
- Git
- Bonezegei Scripting Language (BSL), with the `bzg` command available
- A web browser (Google Chrome, Microsoft Edge, etc.)

### Step 2: Clone the Repository

Open a terminal and execute:

```bash
git clone https://github.com/asnorwahab/BSL_HTTP_and_WebSocket.git
```

Navigate to the project directory:

```bash
cd BSL_HTTP_and_WebSocket
```

### Step 3: Install Dependencies

Install the required project dependencies using:

```bash
bzg install
```

This installs the dependencies specified in the project's `package.json` file.

### Step 4: Run the Web Server

Start the local HTTP server by executing:

```bash
bzg run
```

The command executes the `app.bzg` application and starts the web server.

### Step 5: Open the Portfolio Website

Once the server is running, open a web browser and navigate to:

**http://localhost:8000**

The personal portfolio landing page should now be displayed.
